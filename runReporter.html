Ferramenta de Telemetria e Reporte Automático via Webhook Automated Telemetry & Webhook Reporting Tool

Sistema integrado de suporte ao desenvolvimento, QA e monitoramento de Gameplay Balance. Transmite instantaneamente dados de partidas, screenshots, logs e métricas de desempenho diretamente para o Discord via Webhooks. Integrated development and QA tool for gameplay telemetry. Sends instant match data, screenshots, raw logs, and performance metrics directly to Discord channels via Webhooks.

Fluxo de Funcionalidades & Lógica da Arquitetura Feature Pipeline & System Architecture

1. Disparo In-Game & Reporte Manual de Bugs 1. In-Game Bug Reporting & Manual Triggers

Quando o jogador ou tester clica no botão "Reportar Bug" na interface do jogo: When a player or tester clicks "Report Bug" in-game:

  • O sistema congela o quadro para gerar uma captura de tela (screenshot) instantânea no momento exato do problema. The system freezes the frame to capture an instantaneous screenshot.
  • Coleta metadados de contexto em tempo real: coordenadas no mundo ($X, Y, Z$), vida do jogador, estados dos sistemas, Seed do mapa, IAs ativas e versão da build. Gathers real-time contextual metadata: world coordinates ($X, Y, Z$), player HP, system states, map Seed, active AI entities, and build version.
  • Constrói uma requisição HTTP POST para o Discord formatando a mensagem com títulos, tags de prioridade, screenshot e o arquivo de log completo da partida (.txt). Constructs an HTTP POST request to Discord containing rich formatting, priority tags, screenshot, and raw match log files (.txt).

2. Automação de Logs Event-Driven (Eventos Automáticos de Gameplay) 2. Event-Driven Automated Logging

Além do disparo manual, o sistema escuta eventos globais do jogo para enviar relatórios automáticos no Discord sempre que marcos críticos acontecem: Beyond manual reports, the system listens to global game events to send automated updates on key milestones:

  • Crash do Jogo: Game Crash: Emite um alerta emergencial anexando os últimos rastros da memória e logs da sessão para identificação rápida do erro. Emits an emergency alert attaching stack traces and session logs for rapid triage.
  • Falha na Run (Morte/Derrota): Run Failure (Wipe/Defeat): Registra o momento em que a equipe é eliminada, informando a causa da derrota, tempo de sobrevivência e local do mapa. Logs team wipe events, reporting defeat causes, survival times, and locations.
  • Sucesso na Run (Vitória/Extração): Run Success (Extraction/Victory): Notifica a conclusão bem-sucedida do nível, apresentando os recursos coletados e o status final do time. Notifies successful level completions with extracted loot breakdowns and squad status.
  • Derrota do Boss: Boss Defeated: Notifica quando o chefe da fase é derrotado na Boss Fight, registrando o tempo de combate, dano infligido e quantidade de tentativas. Reports boss defeat events along with combat duration, damage dealt, and attempt counts.

3. Análise de Rentabilidade e Parâmetros de Gameplay 3. Economy & Gameplay Metric Analysis

A cada encerramento de partida (seja por vitória, derrota ou crash), a ferramenta calcula e envia métricas econômicas e estatísticas percentuais: Upon match end (victory, defeat, crash), the system calculates economic percentages and performance metrics:

  • Taxa de Retorno & Rentabilidade: Return Rate & Profitability: Avalia o valor dos recursos coletados em relação ao tempo investido e aos custos operacionais da run (suprimentos e itens consumidos). Evaluates extracted loot value relative to time spent and gear expenditure.
  • Balanço da Economia: Economy Balance: Fornece parâmetros de porcentagem indicando quão rentável está sendo cada estilo de gameplay, auxiliando no ajuste da curva de recompensas do jogo. Provides percentage metrics showing profitability across playstyles to refine reward curves.

4. Integração com o RunDebugger (Análise Top-Down) 4. Integration with RunDebugger

Todos os eventos disparados no Discord (reports manuais ou logs automáticos) acompanham o log bruto da partida: All Discord notifications include attached raw match log files:

  • Os desenvolvedores baixam o log diretamente da mensagem do Discord e o carregam na ferramenta RunDebugger. Developers can download logs from Discord and load them into the RunDebugger tool.
  • O log permite abrir a visão interativa Top-Down da run, navegar pela linha do tempo e analisar visualmente a posição espacial dos jogadores, rota percorrida e histórico de combates no minimapa. Logs reconstruct top-down match views, letting devs scrub timelines and analyze player movement or combat events visually.

Destaques de Produção & Impacto no Projeto Production Highlights & Impact

  • Monitoramento Passivo de Balanceamento: Passive Balance Monitoring: Acompanhamento constante da taxa de sucesso e rentabilidade das partidas sem a necessidade de coletar formulários manualmente. Continuous tracking of win rates and run profitability without manual QA surveys.
  • Triagem de Bugs Rápida e Assertiva: Fast Bug Triage: Elimina relatórios vagos. Crashes e erros chegam no Discord com logs anexados, contexto e imagem do momento do disparo. Eliminates vague bug reports. Crashes deliver attached logs, contextual parameters, and exact screenshots.
  • Auditoria Completa com o RunDebugger: Full Auditability via RunDebugger: Qualquer evento crítico enviado para o Discord pode ser reproduzido espacialmente no minimapa para entender falhas de layout, exploits ou picos desproporcionais de dificuldade. Critical events posted to Discord can be spatially replayed on minimaps to catch exploits or layout bugs.
